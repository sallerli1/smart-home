## S-001 玄关（顶装 ES5，已有）

### 安装参数

| 参数 | 值 |
|------|---|
| 安装位置 | 天花板中心偏室内侧 20cm |
| 安装高度 | 贴顶（2.6-2.8m） |
| 朝向 | 垂直向下 |
| 俯仰角 | 0° |

### 空间信息

- 面积：约 2㎡
- 特点：紧凑过渡空间，门外在检测范围内，鞋柜贴墙无遮挡

### 调试策略

| 调试项 | 方案 |
|--------|------|
| 区段屏蔽 | 入户门方向屏蔽 1-2 个区段，防止门外走廊人员走动触发 |
| 灵敏度 | 中低，小空间避免溢出到门外 |
| 无人延时 | 30 秒，快速通过空间 |

### 注意事项

- 鞋柜上方保持清爽，避免高物遮挡传感器下视锥体边缘

## S-002 厨房（水盆上方，顶装 ES5，已有）

### 安装参数

| 参数 | 值 |
|------|---|
| 安装位置 | 水盆正上方天花板 |
| 安装高度 | 贴顶（2.6-2.8m） |
| 朝向 | 垂直向下 |
| 俯仰角 | 0° |

### 空间信息

- 面积：约 5㎡
- 布局：开放式厨房，水盆靠窗（岛台右侧），岛台左侧为餐边柜，吧台分隔厨房与餐厅
- 传感器分工：S-002 负责厨房操作区，S-014 负责餐厅，S-011 负责吧台

### 调试策略

| 调试项 | 方案 |
|--------|------|
| 区段屏蔽 | 吧台方向屏蔽 1-2 个区段；餐边柜方向适当收束 |
| 灵敏度 | 中等 |
| 无人延时 | 1-2 分钟，做饭时人可能短暂转身但不会离开 |

### 边界分工

- 主覆盖：水盆、岛台右侧操作区、厨房走道
- 边界裁切：岛台左侧（餐边柜方向）交给 S-014/S-011

## S-003 马桶间（顶装 ES5，已有）

### 安装参数

| 参数 | 值 |
|------|---|
| 安装位置 | 马桶正上方天花板（已固定，不可调） |
| 安装高度 | 贴顶 |
| 朝向 | 垂直向下 |
| 俯仰角 | 0° |

### 空间信息

- 面积：约 2㎡
- 隔断：与洗手间、淋浴房之间为玻璃隔断 + 玻璃门
- 风险：ES5 毫米波可穿透普通玻璃，可能检测到相邻空间的人

### 调试策略

| 调试项 | 方案 |
|--------|------|
| 区段屏蔽 | 优先屏蔽朝向玻璃隔断方向的区段，逐段测试穿透范围 |
| 灵敏度 | 中低起步，视穿透情况再下调 |
| 无人延时 | 1-2 分钟 |
| 穿透验证 | 实测时在洗手间/淋浴房有人活动，观察 S-003 是否误触发 |

### 穿透问题处理预案

1. **首选**：区段屏蔽直接解决
2. **次选**：玻璃隔断贴金属膜/锡箔贴阻隔雷达波
3. **兜底**：自动化逻辑排除——当 S-005（洗手间）/ S-006（淋浴房）检测到有人时，忽略 S-003 的触发信号

## S-004 过道（侧装 ES5，待采购）

### 安装参数

| 参数 | 值 |
|------|---|
| 安装方式 | 侧装墙面 |
| 安装位置 | L 转角内侧墙面 |
| 安装高度 | 2.0-2.2m |
| 朝向 | 朝 L 型走廊的开放方向 |
| 俯仰角 | 向下 10-15° |

### 空间信息

- 形状：L 型，约 2m
- 连通：右侧书房（开放）、前方卧室门（常关）、左后方吧台（开放）
- 基础态：人来灯亮/人走灯灭（3500K/80%）
- 夜间态：人来低亮（2700K/5%），22:00-07:00

### 调试策略

| 调试项 | 方案 |
|--------|------|
| 区段屏蔽 | 书房方向、吧台方向严格屏蔽，只保留过道走廊区域 |
| 灵敏度 | 中等 |
| 无人延时 | 30 秒-1 分钟 |
| 夜间模式 | 22:00-07:00 切换低亮参数 |
| 卧室方向 | 关门自然阻隔；开门时可能需额外屏蔽卧室方向区段 |

### 边界分工

- 主覆盖：过道走廊 L 型区域
- 书房方向：S-008 负责书房内部，S-004 只覆盖到书房门口
- 吧台方向：S-011 负责吧台区域，S-004 只覆盖到吧台入口
- 卧室方向：S-009 负责主卧内部，S-004 只覆盖到卧室门口

### 边界验证方法

实测时让一个人分别站在书房内、吧台内、过道内，观察 S-004 的检测状态，确认只有站在过道时才触发。
