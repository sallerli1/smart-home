# 04 - 场景管理规则

## 空间隔离原则

场景按空间生效，不同空间的场景可以同时激活。两人居住时必须支持空间隔离：一个人在主卧睡觉，另一个人在书房打游戏，两个场景互不干扰。

每个空间维护独立的场景状态，场景退出只影响本空间，不会重置其他空间的活跃场景。全屋场景（离家/做家务/回家）才影响所有空间。

### 场景空间归属

| 场景 | 影响空间 | 类型 |
|------|---------|------|
| 离家 | 全屋 | 全屋场景 |
| 做家务 | 全屋 | 全屋场景 |
| 回家 | 全屋 | 全屋场景 |
| 睡觉 | 主卧 + 主卫 | 单空间场景 |
| 起夜 | 主卧 + 主卫 | 单空间场景 |
| 睡前休息 | 主卧 | 单空间场景 |
| 观影 | 客厅 | 单空间场景 |
| 书房游戏 | 书房 | 单空间场景 |
| 做饭 | 厨房 + 餐厅 | 单空间场景 |
| 晚餐 | 餐厅 + 客厅 | 单空间场景 |
| 洗澡 | 卫浴 | 单空间场景 |
| 早晨唤醒 | 主卧 | 单空间场景 |

## 可叠加组合

以下场景可同时激活（不同空间互不干扰）：

- 睡觉 + 书房游戏（老婆睡了你在打游戏）
- 睡觉 + 观影（一个睡一个看）
- 起夜 + 书房游戏
- 观影 + 书房游戏
- 观影 + 做饭
- 观影 + 晚餐（允许叠加：餐厅中亮暖光 + 客厅暗光）
- 做饭 + 书房游戏
- 洗澡 + 观影/书房游戏/做饭

## 冲突处理规则

### 全屋场景覆盖

- 离家触发时，清除所有活跃场景状态
- 做家务触发时，全屋 `xx_做家务=true`（P0 最高优先级覆盖一切）
- 做家务退出时，全屋 `xx_做家务=false`，其他状态自然恢复
- 回家触发时，建立全屋基础态

### 同空间冲突

- 早晨唤醒：必须检查当前是否在睡觉态，只有睡觉态才触发唤醒
- 起夜 + 洗澡：起夜优先，主卫切低亮

### 场景衔接

- 做饭 → 晚餐：手动切换
- 睡前休息 → 睡觉：手动切换
- 起夜 → 睡觉：起夜结束自动回到睡觉态（30 分钟超时兜底）
- 早晨唤醒 → 回家：自然衔接

## 超时兜底机制

场景触发后持续生效，但设置超时兜底防止遗忘：

| 场景 | 超时时间 | 超时后动作 |
|------|---------|-----------|
| 做饭 | 3 小时 | 自动退出，回基础态 |
| 晚餐 | 3 小时 | 自动退出，回基础态 |
| 观影 | 4 小时 | 自动退出，回基础态 |
| 书房游戏 | 6 小时 | 自动退出，回基础态 |
| 做家务 | 2 小时 | 自动退出，回基础态 |
| 洗澡 | 1 小时 | 自动退出，回基础态 |
| 起夜 | 30 分钟 | 自动回到睡觉态 |
| 睡觉 | 不超时 | 持续到早晨唤醒或离家 |
| 兜底规则 | 24 小时 | 所有场景强制重置为基础态 |

## 无人空间联动

场景的空间隔离必须结合"人在检测"：如果某个空间有场景在运行但实际无人，应自动退出该场景并关灯。

### 检测方式

- 主要依据：人体/存在传感器判断空间内是否有人
- 兜底依据：传感器无信号时，以超时时间为准

### 无人退出规则

- 任何有场景激活的空间，传感器检测到无人超过 5 分钟，自动退出该场景，灯光关至基础态
- 适用于：书房游戏、观影、做饭、晚餐等单空间场景
- 不适用于：睡觉、起夜（主卧场景由用户手动管理）

### 睡觉时全屋检查

睡觉场景触发时，主动检查其他空间：

1. 主卧进入睡觉态
2. 逐一检查其他活跃场景空间：
   - 书房有人 → 保持书房游戏态；书房无人超过 5 分钟 → 自动退出，关灯
   - 客厅有人 → 保持观影态；客厅无人超过 5 分钟 → 自动退出，关灯
   - 厨房/餐厅有人 → 保持做饭/晚餐态；无人超过 5 分钟 → 自动退出，关灯
3. 所有无人空间场景退出后，全屋进入静默状态（仅主卧睡觉态 + 全屋基础态关灯）
