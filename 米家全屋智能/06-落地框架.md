# 06 - 场景落地框架

## 一、空间状态与灯光控制方式

每个空间定义可能的状态，每个状态对应固定的灯光控制方式。未标注特定场景的空间保持基础态。

补充说明：睡觉是一个全屋共享的约束状态，各空间都维护自己的 `xx_睡觉` 变量。主卧 + 主卫的 `睡觉` 同时是直接生效的睡觉场景，其他空间的 `睡觉` 主要用于表达夜间静默约束、无人收口和夜间低亮逻辑。

### 灯光控制方式定义

- **常亮**：场景激活期间灯一直亮，不受传感器影响
- **人来灯亮/人走灯灭**：传感器驱动，场景只设定色温和亮度参数
- **常灭**：灯关闭
- **渐亮/渐灭**：亮度渐变过渡

## 三、区域状态变量表

每个空间维护独立的状态变量，每个状态是一个独立布尔变量，不共用。

### 状态优先级

当多个状态同时为 true 时，优先级最高的状态决定实际灯光表现：

| 优先级 | 状态 | 说明 |
|--------|------|------|
| P0（最高） | 离家、做家务 | 绝对覆盖，全屋统一 |
| P1 | 观影、晚餐、做饭、洗澡、起夜 | 具体场景 |
| P2 | 游戏、工作、睡前休息 | 具体场景 |
| P3 | 睡觉、夜间态 | 睡眠与夜间低亮约束 |
| P4（最低） | 基础态 | 默认状态 |

实际状态 = 所有=true 状态中优先级最高的那个。

### 做家务简化规则

做家务不需要快照机制，只需设置最高优先级状态：
- 触发：所有空间 `xx_做家务=true`，其他变量不变
- 退出：所有空间 `xx_做家务=false`，其他变量自然生效
- 退出后系统自动取剩余=true 中最高优先级状态

## 四、全屋灯光氛围模式

独立于空间状态变量，专门控制基础态空间的亮度和色温。

### 模式定义

| 模式 | 色温 | 亮度 | 适用情况 |
|------|------|------|---------|
| 正常模式 | 3000K | 60% | 日常在家默认 |
| 明亮模式 | 4500K | 100% | 做家务时全屋 |
| 温馨模式 | 2700K | 40% | 观影/晚餐/游戏时其他空间 |
| 安静模式 | 2700K | 15% | 睡前/睡觉/洗澡时其他空间 |

| 睡觉退出 | → 正常 |
| 起夜 | 不变（保持安静） |
| 观影 | → 温馨 |
| 观影退出 | → 正常 |

| 做家务退出 | → 正常 |
| 洗澡 | → 安静 |
| 洗澡退出 | → 正常 |

### 灯光氛围优先级

多个场景同时激活时，mood 取优先级最高场景对应的 mood：

| 场景优先级 | mood |
|-----------|------|
| 做家务(P0) | 明亮 |
| 观影/晚餐/洗澡/起夜(P1) | 温馨 |
| 游戏/工作/睡前休息(P2) | 温馨 |
| 睡觉(P3) | 安静 |
| 基础态(P4) | 正常 |

### 完整灯光计算逻辑

```
FOR 每个空间:
  actual_scene = 该空间所有=true 状态变量中优先级最高的
  IF actual_scene 有专属灯光参数（观影/做饭/游戏/洗澡等）:
    灯光 = 该场景的专属参数
  ELSE:
    灯光 = mood_lighting_mode 对应的参数
```

## 五、设备条件控制

场景触发时，每个设备动作内嵌条件检查，不满足条件则跳过。

### 灯光条件

- 开灯前检查：本地区域光照 < 阈值（避免白天开灯）
- 关灯条件：传感器无人超时
- 色温/亮度：由当前最高优先级状态决定

### 开窗器条件

- 开窗前检查：本地雨水传感器=未下雨 AND 本地室外温湿度传感器=未高温/未高湿 AND 空调未运行
- 卧室夜间不开窗
- 离家时可通风窗户打开（满足上述条件时）

### 窗帘条件

- 观影：关纱帘（如光照充足则不关）
- 睡觉：全关
- 离家：全开（采光）
- 白天在家：布帘开，纱帘按本地光照自动

### 空调条件

- 离家：关闭所有空调
- 回家：已预开则切常规，否则语音提醒后开启
- 睡觉：切换睡眠温控
- 空调运行中窗户开：暂停空调
- 温度合适，不开空调
